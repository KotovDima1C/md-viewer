MD Viewer — лёгкий просмотрщик Markdown для Windows
https://github.com/KotovDima1C/md-viewer

УСТАНОВКА
1. Распакуйте архив в любую папку.
2. Запустите setup.cmd (двойной клик).
   Программа скопируется в %LOCALAPPDATA%\Programs\md-viewer
   и станет доступна для файлов .md. Права администратора не нужны.
3. Если .md по-прежнему открываются другой программой:
   правый клик по .md -> «Открыть с помощью» -> «Выбрать другое приложение» ->
   «Выбрать приложение на компьютере» -> вставьте в поле «Имя файла»
   %LOCALAPPDATA%\Programs\md-viewer\md-viewer.exe -> «Открыть» -> «Всегда».

Если Windows покажет «Система Windows защитила ваш компьютер» —
нажмите «Подробнее» -> «Выполнить в любом случае»: программа не подписана сертификатом.

ЧТО НУЖНО
Windows 10 или 11. Движок Edge WebView2 уже есть в Windows 11
(для Windows 10 — https://developer.microsoft.com/microsoft-edge/webview2/).
.NET ставить не нужно — он внутри.

КЛАВИШИ
Esc / Ctrl+W — закрыть      Ctrl+F — поиск         Ctrl+O — открыть файл
Ctrl+E — править в Блокноте  Ctrl+колесо — масштаб  F5 — перечитать
Alt+← / Alt+→ — назад/вперёд по ссылкам              Ctrl+P — печать или PDF
Справа вверху — тема: тёмная / светлая / как в Windows.
Слева — оглавление: наведите на полоски.

УДАЛЕНИЕ
Запустите uninstall.cmd.
